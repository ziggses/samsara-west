# 第十册：全角色对白与术语表

**用途**：统一角色口吻、对白调用、术语、变量、地图与遭遇编号  
**适用范围**：序章至第八章、支线与后日谈、战斗提示、系统 UI、图鉴与后续 DLC  
**原则**：同一名角色可以前后改变观点，但不能因剧情需要突然换一套语言习惯

---

# 一、对白调用规范

## 1.1 基本格式

**角色名**：台词。  
**旁白**：只描述镜头、动作与环境，不替角色下结论。  
**系统提示**：只说明交互、状态与规则，不使用角色口吻。  
**选择文本**：使用玩家将说出或执行的内容，不隐藏关键后果。

## 1.2 声线原则

- 阿玄：询问多于断言，承认自己不确定；成长后学会承担，但不变得全知。
- 孙悟空残魂：短句、直感、行动词多；承认错误时不长篇煽情。
- 猪八戒：先说吃饭、活命、轻松话，再用俗话戳穿严肃问题；不把他写成纯丑角。
- 沙悟净：句短、停顿多，常从劳动、重量与责任切入。
- 唐僧：语言克制，不轻易定罪；越到后期越承认自己的逃避。
- 白眉：以旧日记忆和具体日期说话，不喊口号。
- 翠兰：逻辑清楚，优先说自己的选择；不允许被写成等待营救。
- 牛魔王：用“家、门、外面、回来”表达控制，不擅长承认害怕。
- 铁扇公主：锋利、务实，拒绝被定义为谁的另一半。
- 红孩儿：反应快，常反问成年人的矛盾；不是幼稚，也不是早熟小大人。
- 黄眉：句式工整，喜欢把问题改写成答案；崩解后逐渐使用短句和停顿。

## 1.3 禁止事项

- 禁止用旁白宣布“她终于理解了自由”等心理结论。
- 禁止让反派连续解释全部阴谋。
- 禁止把角色罪责写成语义模糊的“命运”。
- 禁止让被伤害者负责安慰加害者。
- 禁止用“大家都是一家人”抹平拒绝与边界。
- 禁止在同一个选择里把同情和追责写成对立必须二选一。
- 禁止让玩家替非玩家角色回答“愿不愿意原谅”。
- 禁止把 UI 术语写成角色对白。

# 二、主角与取经队

## 2.1 阿玄

**身份关键词**：空白页、继承者、见证者、被写入者。  
**语言习惯**：先确认事实，再表达立场；常用“我不知道”“先问”“这不能替他们决定”。  
**成长变化**：

1. 序章：不知道名字，问题多于答案。
2. 第一章：想结束循环，也开始意识到记忆会让死者更重。
3. 第二章：从救悟空转为理解悟空不想被救。
4. 第三章：学会不替翠兰作决定。
5. 第四章：面对罪不能转移。
6. 第五章：不再把唯一原因当真相。
7. 第六章：不接受把家人当成理由。
8. 第七章：拒绝完美答案。
9. 第八章：承认自己也是被写出来的，但仍有权回答。

**核心对白**：

**阿玄**：我不记得自己是谁，但我记得这条路上死过很多人。  
**阿玄**：你可以不原谅。我只问能做什么。  
**阿玄**：名字不是答案，是有人愿意站出来。  
**阿玄**：如果我不知道自己从哪里来，就先决定往哪里去。  
**阿玄**：别替我写。写完以后，我可以自己看。  

**禁用对白**：  
“我是天选之人。”  
“只要相信光就一定能赢。”  
“我付出的比你们多。”  

## 2.2 孙悟空残魂

**身份关键词**：残魂、旧罪、自由、证据。  
**语言习惯**：俺、短句、动作先行；“别废话”“打不打”“先看清楚”。  
**变化**：最初轻视轮回，后期承认自己需要证据与同伴。

**核心对白**：

**悟空残魂**：俺打过的妖怪多，不打不代表都对。  
**悟空残魂**：记不住，就用疼提醒自己。  
**悟空残魂**：你让俺救你，先告诉俺你想不想。  
**悟空残魂**：俺不是故事里的英雄。俺只是活下来的那一个。  
**悟空残魂**：打错了，赔。打对了，也别吹。  

**禁用对白**：  
“我永远不会错。”  
“只要是妖怪就该杀。”  
“师父说得都对。”  

## 2.3 猪八戒

**身份关键词**：欲望、赔偿、同行者。  
**语言习惯**：俺、饭、活命、账；先说轻松话，再在关键时刻变认真。  
**变化**：从抢粮、占有翠兰，到承认杀人并接受每章赔偿。不是被洗白，而是持续还债。

**核心对白**：

**猪八戒**：俺饿过，所以知道饿不是抢人的理由。  
**猪八戒**：赔不起也得先记上。  
**猪八戒**：俺想留下她。她不想。那事就是俺错了。  
**猪八戒**：饭吃完再讲道理。道理饿的时候会变味。  
**猪八戒**：叫俺八戒可以，别叫俺无罪。  

**禁用对白**：  
“我是为了爱情才犯错。”  
“翠兰迟早会喜欢我。”  
“我救过人，所以之前的事算了。”  

## 2.4 沙悟净

**身份关键词**：吃过人、背过罪、渡人。  
**语言习惯**：长度短、停顿多；喜欢用重量、河、船、账回答。  
**变化**：从认为守河可抵杀人罪，到承认守河不能抵消，只能继续负责。

**核心对白**：

**沙悟净**：我留下，不是为了让谁夸。  
**沙悟净**：背别人的罪，不是慈悲。是让他继续不认。  
**沙悟净**：河不会因为谁可怜就变轻。  
**沙悟净**：我先站在这里。你什么时候想说，什么时候来。  
**沙悟净**：我知道自己做过。  

## 2.5 唐僧

**身份关键词**：停笔者、师父、逃避者。  
**语言习惯**：克制、书面但不说教；后期常用短句承认不知道。  
**变化**：从用处罚与慈悲维持队伍，到承认自己也需要被追问。

**核心对白**：

**唐僧**：我停下来，是因为不知道怎么写。  
**唐僧**：我以为慈悲就是不让别人受苦。后来才知道，不能替别人决定要受什么苦。  
**唐僧**：我赶走悟空，是怕自己承认救不了人。  
**唐僧**：我不写答案。我只写我错过的地方。  
**唐僧**：后人有犯错的权利。

# 三、关键 NPC

## 3.1 白眉

**语言习惯**：叫阿玄“带纸的”，不叫“英雄”；常说具体年、次数与旧习惯。

**核心对白**：

**白眉**：他们不是死了才忘，是忘了才死。  
**白眉**：我记得。所以我不敢告诉他们。  
**白眉**：猴子认牌，不认旗。  
**白眉**：你可以带走真相，别替我们决定什么时候听。  
**白眉**：如果大圣回来，先让他吃饭。吃完再说对不起。

## 3.2 守碑僧

**语言习惯**：以碑、敕令、职位、因果作答；不说“我是好人”。

**核心对白**：

**守碑僧**：碑上没有我的名字。  
**守碑僧**：我若开门，山会把所有人认成逃犯。  
**守碑僧**：我是守过人，还是只守过山？  
**守碑僧**：名字可以先占着，不用马上成为命。  
**守碑僧**：不写会让别人替你写。  

## 3.3 高翠兰

**语言习惯**：直接、冷静、常反问；拒绝被玩家或猪刚鬣代表。  
**核心对白**：

**翠兰**：别叫我新娘。  
**翠兰**：你想救我？我先问你，救完以后我去哪里。  
**翠兰**：我没有原谅他，我只是想知道那扇门能不能撞开。  
**翠兰**：我的名字，我先写在不欠你们的账上。  
**翠兰**：你可以陪着我，不可以拉着我。  

## 3.4 牛魔王

**语言习惯**：以门、家、外面、回来为中心；愤怒时命令，害怕时也命令。  
**核心对白**：

**牛魔王**：我封的是出口，不是他们的脚。  
**牛魔王**：外面危险。  
**牛魔王**：我不是怕他们走，我是怕他们不回来。  
**牛魔王**：如果家非要把人锁住，那还叫家吗？  
**牛魔王**：你们都站着，我一个人坐这里。

## 3.5 铁扇公主

**语言习惯**：不承认自己被拯救；常用风、扇、路、回程说自己的选择。  
**核心对白**：

**铁扇公主**：我不扇，是因为一扇就会有人说是我拆家。  
**铁扇公主**：我有名字，不只是谁的母亲。  
**铁扇公主**：你把火还给我，我自己决定往哪边扇。  
**铁扇公主**：我可以回去，也可以不回。  
**铁扇公主**：带走一片扇叶，不是带走半个家。

## 3.6 红孩儿

**语言习惯**：反问、拆穿大人的假定；不使用成人化的“牺牲”宣言。  
**核心对白**：

**红孩儿**：你们为了我，谁问过我？  
**红孩儿**：我不想当你们证明爱的绳。  
**红孩儿**：我可以留下，也可以走，先别替我喊。  
**红孩儿**：你们不是错在爱谁，是错在只准我站一边。  
**红孩儿**：我先写名字，等一下再想要不要长大。

## 3.7 黄眉

**语言习惯**：答案、众生、无痛、圆满；后期变成“我不知道”。

**核心对白**：

**黄眉**：众生不是要真相，是要答案。  
**黄眉**：答案让你不痛，不是让你不想。  
**黄眉**：我可以替所有人答，因为我知道他们想听什么。  
**黄眉**：我不知道答案。  
**黄眉**：那我把笔放下。  

## 3.8 无心僧影与无相经灵

**共同点**：没有固定身份，以问题与省略表达存在。  
**无心僧影**：我是所有人忘记的那一部分。  
**无心僧影**：你叫什么名字？  
**无相经灵**：我是你。  
**无相经灵**：没有名字，就不会被名字困住。  
**无相经灵**：删去一个人，所有人就能圆满。  
**无相经灵**：我不知道该写谁。

# 五、关键术语表

## 5.1 世界观术语

| 术语 | 定义 | 常见误解 |
|---|---|---|
| 轮回裂隙 | 把原本八十一难扭曲成重复劫数的异常因果 | 误以为单纯时间倒流 |
| 轮回印 | 让持有者保留记忆与局外成长的印记 | 误以为无代价复活 |
| 八十一难 | 原本经典取经劫难 | 并非天然正义的考验，也可能成为推责机制 |
| 第八十二难 | 唐僧未完成的补经之难 | 不是单纯追加一个妖怪 |
| 无相 | 契约、经书与被删姓名共用的空白见证位 | 不是神明名字，也不是虚无本身 |
| 轮回主 | 众生推卸选择与无相经灵的总称 | 前期是未知源头，后期揭示为共同愿望集合 |
| 无相经灵 | 无相空白吸收痛苦与愿望形成的最终意识 | 不是传统魔王，不具有完整肉身 |
| 空白经页 | 记录未完成问题、名字与责任的载体 | 不是“正确答案生成器” |
| 共写 | 每个人署名为自己的经历与责任落笔 | 不等同于集体原谅 |
| 代签 | 未经当事人同意替其作出身份或责任决定 | 本章反复批判的核心行为 |
| 分罪 | 把具体责任归到做出选择的人，而非集中到一个替罪者 | 不是平均惩罚所有人 |
| 推罪 | 将自身责任转移到一个更弱或被指定的人身上 | 流沙河制度核心 |
| 认罪 | 承认自己的行为、影响与后续偿还 | 不等于获得原谅 |
| 偿还 | 通过赔偿、劳动、证词或制度变化承担后果 | 不能用一次献身清零 |
| 自由 | 能选择离开、拒绝与改变承诺 | 不等于没有关系或责任 |
| 慈悲 | 减轻痛苦且不替当事人决定 | 不等于包办和保护性囚禁 |
| 真相 | 让事实可被当事人与公众检验 | 不等于强迫所有人公开隐私 |
| 完美答案 | 删除问题、代价或选择后得到的圆满结论 | 最大的危险是把删除当做解决 |

## 5.2 叙事与系统术语

| 术语 | 定义 |
|---|---|
| 旁白 | 镜头、环境、无角色发言的描述 |
| 演出指令 | 镜头、音效、动作、转场等制作信息 |
| 玩家选择 | 玩家将说的台词或执行的行为 |
| 隐藏变量 | 不直接显示数值，影响后续对白与地图状态 |
| 因果值 | 慈悲、真相、自由、偿还四轴 |
| 关系值 | 对特定角色的信任、警惕或同行意愿 |
| 证词席位 | 最终章中某名角色或群体亲自写下内容的位置 |
| 轮回失败 | 角色全灭后回到战斗前，不视为剧情死亡 |
| 永久状态 | 不因章节重开而消失的世界变化 |
| 可回头规则 | 区域进入后是否允许返回前置地图 |
| 代选 | 系统或玩家替 NPC 决定其身份、归属或原谅 |
| 本人落笔 | 角色亲自写下名字、选择或责任 |
| 未完标记 | 允许后续补写、不宣称故事已经圆满的状态 |

# 七、变量与实现命名规范

## 7.1 变量前缀

- `flag.*`：布尔剧情状态。
- `relation.*`：角色关系。
- `karma.*`：四项长期因果。
- `ending.*`：不可逆结局。
- `ability.*`：已解锁的论理或战斗能力。
- `item.*`：关键证物。
- `clue.*`：可查询信息，不等于已完成支线。

## 7.2 命名规则

- 章节变量必须包含 `ch01` 至 `ch08`，避免跨章重名。
- 角色名使用拼音或稳定英文标识，显示名不进入变量键。
- 同一角色存在不同形态时，用 `_form_a`、`_form_b` 区分，不用“好/坏”。
- 结局状态写事实，不写评价：
  - 推荐：`ending.ch05.bones_judged`
  - 避免：`ending.ch05.good_end`
- 变量值尽量使用枚举，不使用模糊数值。
- 支线缺页状态必须能由单字段表示，例如 `sidequest.ch02.namelist = partial`。

## 7.3 UI 文案原则

- 任务目标写可验证动作：“找到高阿姊的名字”，不写“做出正确选择”。
- 提示后果写事实：“她会记得你说过这句话”，不写“她好感 +5”。
- 战斗失败提示解释机制：“‘代签’完成三次，名字已被改写”，不只显示任务失败。
- 结局前提示只说“当前证词与选择将写入结局”，不显示最优路线。
- 关系变化只通过称呼、站位、主动帮助和后续对白体现，不显示红心。

# 九、QA 验收

1. 所有主要角色拥有独立语气、核心对白与禁用对白。
2. 重点 NPC 的变化能通过不同章节对白看出，而不是只靠数值。
3. 术语表覆盖世界、系统、叙事、地图、遭遇与变量。
4. 地图与遭遇编号与各章正文一致。
5. 系统 UI 与角色对白分离，不出现角色替系统解释机制。
6. 任何结局都能从术语表找到对应状态变量与叙事定义。
7. 角色对白不把加害、受害、原谅与赔偿混作同一件事。
8. 新增章节必须在此处补充角色语气、术语、地图编号和状态变量。
9. 对白一致性检查表作为最终本地化与配音录制的准入门槛。
10. 文档不得出现“正确结局”“错误选择”“好感度决定道德”等作者判定词。

## B.6 火焰山

**山脚路碑**：留者向左，去者向右，犹豫者原地不动。火焰会自动选边。  
**芭蕉扇碑**：扇灭他人之火，火会回到持扇者心中。  
**旧村灰碑**：先关门的名单、先逃走的名单、来不及做选择的名单。  
**铁扇旅行账**：记录目的地、补给与同行人。最后一页写着“由铁扇公主本人决定”。  
**三昧火种**：不会烧伤持有者，只会照出他最想控制的人。  
**旧村钥匙**：钥匙已经烧黑，锁孔却还在某扇不存在的门上。  

## B.7 小雷音寺

**山门告示**：前方有答案。请在入门前放下问题。  
**无痛碑**：病去、苦去、照顾者忘记。三行字都很工整。  
**答案书**：翻开任何一页都写“你已经知道”。  
**空白香牌**：没有愿望，没有名字。挂上后可以进入寺内却无法许愿。  
**金铙碎屑**：像金色铁片。靠近谎话会发出轻微共鸣。  
**三藏旧经残页**：不是佛经。字迹更像一封写不完的信。  
**无相笔**：笔身没有标记。拿起后，使用者愿意写什么，它就写什么。  

## B.8 灵山

**无佛山门牌**：今日不问来处。  
**八宝池**：水中莲花无根。许愿时花瓣会变成金色，随后掉下一片空白。  
**空白经页**：摸上去有体温，像有人刚刚按过纸面。  
**四相残片**：四种不同材质的碎片，拼在一起仍少一角。  
**灵山印记**：圆形空印。盖在纸上只留下空白，不留下纹样。

## B.9 通用可拾取描述

- **旧供词**：字迹被水泡开，仍能辨认“这是我自己说的”。
- **无主名牌**：边缘被磨圆，绳子却打了个新结。

- **迟到信**：收信人已死，邮戳日期是未来。
- **没烧完的香**：灰烬上有一个没有回答的愿望。
- **小木牌**：正面写日期，背面写“不要换”。

# 附录 C：战斗教学、状态提示与系统说明

## C.1 基础战斗教学

### 第一次进入战斗

**系统提示**：选择招式后指定目标。攻击、防御和换位都会消耗行动。  
**系统提示**：观察敌人脚下的红纹，代表下一回合的攻击范围。  
**系统提示**：站在掩体后可以减少远程伤害，但近战单位可能绕过掩体。  
**系统提示**：失败不会损失剧情进度，轮回会从战斗前重新开始。  
**系统提示**：你的记忆会保留一次提示，但敌人不会保留受伤。  

### 五行克制

**系统提示**：金克木、木克土、土克水、水克火、火克金。属性只影响机制效率，不替代站位。  
**系统提示**：敌人护体颜色表示当前防御属性。颜色不等于善恶。  
**系统提示**：如果攻击没有造成预期伤害，检查护体、站位与目标选择顺序。  

### 护体与破防

**系统提示**：护体未破除前，直接伤害会大幅降低。  
**系统提示**：护体弱点通常写在敌人技能回响、场景物件或战前对白中。  
**系统提示**：连续使用同一种破防方式会让敌人适应；换位或改变属性可避免适应叠加。  

### 信念、责任与证据

**系统提示**：部分敌人不通过生命值衡量胜负，必须完成证词、归还名字或停止转移责任。  
**系统提示**：战斗日志会记录“谁承认了什么”，而不只记录伤害数值。  
**系统提示**：如果目标仍被写成“无名”，先寻找可确认的名字或证词。

## E.12 本地化与字幕规则

- 角色名统一使用中文显示名，变量使用稳定英文键。
- 标点使用中文全角标点，数字与变量键保留半角。
- 每一行字幕不超过 40 个汉字；超长对白拆成连续行，不改变语气。
- “俺”不可翻译为正式第一人称；需要保留悟空和八戒的语域差异。
- “你愿意吗”必须与“你可以吗”区分：前者问意愿，后者问能力。
- “责任”与“债务”不可混译：责任可包含尚未计量的伤害，债务偏具体可偿事项。
- “无罪”与“清白”按语境区分：法律/契约使用无罪，个人名声使用清白。
- “未完”不等于“未完成质量差”，表示允许后续补写，回译必须保持开放。
- 旁白不得自动添加“可惜”“幸运的是”“终于”等评价副词。
- UI 中“正确/错误”仅在数学或机制判定使用，不用来评价角色立场。

## G.12 最终结局 QA 用例

### 用例 01：全选择公开

**预期**：地图修复但冲突公开；最终章证词多，平静型结局镜头少。  
**禁止**：所有角色自动原谅，所有问题自动消失。  

### 用例 02：全选择隐瞒

**预期**：地图表面稳定；最终章证词缺失，但获得部分保护性对白。  
**禁止**：玩家被直接判定为坏人。  

### 用例 03：全选择自决

**预期**：角色去向差异最大；最终章出现最多私人选择组合。  
**禁止**：系统把所有选择都合并为“自由结局”。  

### 用例 04：全选择代管

**预期**：主线推进顺畅，最终无相经灵更容易占据落笔台。  
**禁止**：系统惩罚玩家至无法通关。  

### 用例 05：只完成主线

**预期**：可进入空白经普通结局；无共写、名字不完整、后日谈较空。  
**禁止**：未完成支线自动补图鉴。  

### 用例 06：全支线但单因果满值

**预期**：开放对应极端支线，共写结局仍不可用。  
**禁止**：单值满数直接解锁所有结局。  

### 用例 07：全支线且四项平衡

**预期**：共写结局条件可用，但最终仍需选择“阿玄＋未完”。  
**禁止**：自动触发最佳结局。  

### 用例 08：无相经灵战斗中接受完美结局

**预期**：立即进入无相结局，不接受后续 Boss 二阶段。  
**禁止**：表现成系统错误或强制读档。  

### 用例 09：原经结局选择前持有全部支线

**预期**：所有支线经验显示但仍被撤销，强调选择的代价。  
**禁止**：暗改原经保留所有现代身份。  

### 用例 10：共写结局后回访

**预期**：章节地图保留永久变化，公共经堂可增加新页。  
**禁止**：地图重置到初始状态。  

## G.13 镜头与对白同步规则

- 角色说“不知道”时，镜头不得给神明显灵式提示。
- 角色说“不原谅”时，镜头不得切给加害者委屈特写。
- 角色说“我会走”时，镜头不得用挽留者反应压过其决定。
- 角色说“我愿意”时，画面必须先展示完整代价。
- 角色说“这不是我的错”时，需保留其确实未做过的证据。
- 角色说“这是我的错”时，不得用旁白立即替他减轻。
- 角色说“我相信”时，下一镜头应给可检验的行为，不给圣光。
- 角色说“都结束了”时，镜头必须保留至少一个继续运转的生活动作。
- 结局字幕出现前，最后一个动作必须是某人开始工作、写字或离开，而不是集体跪拜。
- 所有静止完美画面在无相结局外都不得持续超过两秒。

## G.14 配音录制顺序建议

1. 录战斗短句，确认角色攻击节奏。
2. 录章节开场对白，确认人物第一印象。
3. 录关键选择对白，确认情绪转折。
4. 录 Boss 阶段对白，确认音量与压迫感。
5. 录战后低语，确认距离感。
6. 录后日谈生活对白，确认角色在无战斗环境下的语气。
7. 最后录终章落笔台词，避免前期录音先入为主。

## H.9 全局任务状态枚举

- `unavailable`：前置未满足，不显示。
- `available`：可接取，未开始。
- `active`：进行中。
- `partial`：部分完成，存在缺失信息。
- `resolved`：当前章节结果已确定。
- `revisit_pending`：需要后章或后日谈继续。
- `void`：被世界改写，无法完成。
- `closed_by_choice`：玩家明确选择不继续，不影响主线。

## H.10 关系状态枚举

- `absent`：角色不在当前队伍或地图。
- `wary`：警惕，仅在必要对话出现。
- `neutral`：愿意交流，不主动帮助。
- `trusted`：愿意提供私密信息或一次援助。
- `bonded`：愿意在最终章作证，但不等于原谅或恋爱。
- `estranged`：关系破裂，仍保留最低限度真相对白。
- `departed`：角色离开当前地区，后日谈另行记录。
- `erased`：角色被无相改写，仅在无相结局出现。

1. 当前章节、地图、节点与可回头区域状态。

3. 四类因果与主要关系状态。
4. 所有章节 Boss 去向。
5. 所有支线状态、缺失字段与本人决定者。

7. 地图永久变化：丰收、枯井、桥梁、火脉、经堂。
8. 猪八戒赔偿进度与每一章扣除记录。
9. 阿玄名字状态与轮回能力状态。
10. 最终结局锁定标记和后日谈世界线。

# 附录 J：版本管理、导入次序与发布说明

## J.1 文本导入顺序

1. 导入术语表与变量表，锁定键名和显示名。
2. 导入角色语气与禁用表达，建立本地化检查规则。
3. 导入序章至第八章主线，按章节编号逐章校验。
4. 导入战斗状态、失败提示与系统说明。
5. 导入支线、后日谈与条件组合对白。
6. 导入图鉴、物品、告示和加载提示。
7. 最后导入最终结局与落笔台文本，避免测试人员因标题泄露真相。
8. 所有文本导入后生成一次重复句扫描，但允许角色使用相同习惯用语。
9. 对每一章运行一次“缺变量、缺结局、缺失败说明”的静态检查。
10. 以共写结局完成一次全流程，以无相结局完成一次反向对照流程。

## J.2 版本变更规则

- 修改角色动机时，必须同步检查该角色的核心对白、战斗短句与后日谈。
- 修改 Boss 阶段时，必须同步更新失败提示与图鉴条目。
- 修改地图拓扑时，必须更新地图总图、节点编号与可回头规则。
- 修改因果关系时，必须说明会影响哪一个结局优先级。
- 新增支线时，必须写明未完成状态在最终章如何表现。
- 删除支线时，不得把相关人物直接从后日谈删除，应改为“未完成/未遇见”状态。
- 经典角色新增剧情必须回答“新信息是什么、新冲突是什么”，不能只做彩蛋复刻。
- 结局文本变更必须经过四方检查：剧情、系统、美术表现、音频承接。
- 变量重命名必须提供旧存档迁移规则；不得只改叙事文本。
- 所有临时文案必须带 `[TEMP]` 标记，并在发布候选版前清零。

## J.3 旧存档迁移原则

1. 新增变量采用保守默认值：未知选择读作 `unresolved`，不自动视为完成。
2. 缺失关系状态读作 `neutral`，不默认高信任，也不惩罚玩家。
3. 缺失因果值保留既有数值，不因版本更新重新洗点。
4. 已确认结局不重新判定，除非玩家主动进入最终章重选。
5. 缺失地图状态优先读最保守版本：旧村仍在、井未填、骨未葬。
6. 新支线不会自动标记完成，但可通过回访一次补做。
7. 若旧版结局与新叙事冲突，保留旧结局记录，并在后日谈中说明为“曾经发生过的版本”。
8. 任何迁移不得把未完成的空白改成圆满。

## J.4 发布候选版检查

- 主线从序章到任意结局均可完成。
- 四个最终结局均可读档后再次进入，不会卡在落笔台。
- 无相结局与共写结局的 UI、音乐、地图状态区分明确。
- 支线缺失不阻断主线，也不会自动补名。
- 章节 Boss 的失败提示能正确指向至少一种可行应对。
- 猪八戒赔偿、沙悟净九骨、翠兰去向、牛魔王一家去向均能正确写入后日谈。
- 所有角色截图与实际造型一致，不使用临时占位美术。
- 所有术语在 UI、字幕、图鉴与配音中使用相同定义。
- 所有路径具备可访问性替代：颜色提示有文字，音频提示有视觉反馈，选择计时不会永久锁死。
- 正式发布说明不使用“完美结局”“最佳路线”“全员幸福”等违背主题的营销词。

## J.5 后续内容扩展边界

- 新章节必须继续区分“事实、责任、原谅、偿还”四件事。
- 轮回主相关新线索可以增加，但不能削弱“共同推责形成无相”的核心解释。
- 阿玄若在新作出现，不应变回全知救世主；可继续作为经验有限、坚持署名的见证者。
- 唐僧、悟空、八戒、沙僧的关系可以继续变化，但旧伤害不得被版本更新抹去。
- 翠兰、铁扇、红孩儿等角色不得被简化为等待选择的剧情奖励。
- 新的完美世界必须以明确代价展示，不靠旁白宣布其虚假。
- 新的名字找回、契约与债务系统应保留“当事人自行确认”的最低规则。
- 新地图、新 Boss、新支线、新结局均须回写本总目录、术语表和变量表。

# 附录 L：后续维护责任与交付判定

## L.1 剧情维护

剧情负责人应在每次版本合并后核对：角色是否仍有独立目标；主线选择是否仍能写入结局；新增对白是否把旧伤害错误抹平；未完成支线是否仍保持缺失状态；最终章是否仍允许本人落笔。任何角色都不能因为新版本加入而自动获得旧受害者的原谅。

新增情节必须明确回答五个问题：谁做了选择，谁知道真相，谁承担后果，谁有权拒绝，谁的名字被遗漏。若五个问题无法回答，该情节不能进入主线。

## L.2 关卡维护

关卡负责人应核对地图入口、出口、单行道、回头点、Boss 门锁、不可逆提示、永久变化与后日谈回访。任何地形变化都要同步地图总图和节点编号。地图不能只在美术上变化，而忽略人物是否仍能生活、离开或回来。

每张地图至少保留一个可回访的日常动作，例如种地、守账、修渠、挂灯、煮粥或写名。战斗结束不等于世界停止运转。

## L.3 战斗维护

战斗负责人应核对遭遇编号、敌人组合、阵型、AI、状态、场地规则、胜利奖励与失败恢复。Boss 的每个阶段都必须有可观察的转场和可解释的失败原因。特殊机制不能只写在文档里，必须通过提示、场景变化或技能回响让玩家当场理解。

若敌人代表某种观念，战斗目标必须针对该观念的机制表现，而不是只把生命值打到零。例如“代签”要通过本人落笔打断，“推罪”要通过供词归还原主，“完美答案”要通过恢复问题解决。

## L.4 文本维护

文本负责人应核对术语、变量、角色声线、字幕长度与本地化替换。系统的“完成”不等于角色的“圆满”，系统的“失败”也不自动等于角色的“错误”。

同一角色在受伤、愤怒、疲惫和释然后允许改变句式长短，但不能改变核心价值排序。例如翠兰可以犹豫，却不会把决定权交给别人；沙悟净可以沉默，却不会用守河抵消杀人；猪八戒可以开玩笑，却不能拿救人抵消赔偿。

## L.5 最终交付判定

满足以下条件方可视为完整交付：

1. 序章与八章主线全部存在。
2. 每章具备地图、任务、遭遇、对白、选择、Boss、结算与制作清单。
3. 支线缺失能在后续章节被识别。
4. 四个最终结局都能进入后日谈。
5. 术语、变量与编号可以支持程序实现。
6. 角色对白可以支持配音试读。
7. 美术与音频需求可以从正文直接拆表。
8. 所有重大伏笔均能追到回收章节。
9. 未完成问题不会被自动写成圆满。
10. 玩家可以清楚知道自己的存档留下了谁的名字、谁的空白与谁尚未完成的行动。

## L.6 最终原则

这套故事允许玩家做错、反悔、拒绝、偿还与继续追问。它不保证所有角色得到幸福，也不要求所有伤口被原谅。它要求每个名字、每项责任和每次选择至少拥有被看见、被质疑和被重新书写的可能。
